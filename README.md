# На полях — Markdown-карточки

Сайт для чтения заметок с телефона. Один Markdown-файл — одна карточка любой длины. Внизу — «Назад», случайная карточка 🎲 и «Вперёд». Папки, поиск и последняя карточка запоминаются в браузере. Ссылку на отдельную карточку можно скопировать из адресной строки.

## Открыть сайт

https://TemaReka.github.io/Reading-Designing-Data-Intensive-Applications-/

## Обновить заметки

Дважды нажать **`update.cmd`**. Скрипт прочитает выбранные папки, соберёт карточки и отправит результат в GitHub Pages. Изменения появятся после завершения публикации GitHub (обычно несколько минут). Автоматического чтения новых файлов нет.

Нужны уже установленные Python 3.11+, Git и сохранённый вход GitHub в Git Credential Manager. Дополнительные пакеты устанавливать не требуется.

## Выбрать локальные папки

Дважды нажать **`choose-folders.cmd`**. Или из PowerShell в этой папке:

```powershell
.\update.cmd --choose
```

Откроется обычное окно выбора папки; можно последовательно добавить несколько. Выбранный список **заменяет** прежний. Все подпапки читаются рекурсивно. Или отредактируйте `directories` в `sources.json`: пути относительно проекта либо абсолютные; в JSON для Windows используйте `/` или `\\`.

На сайте кнопка «Папки» выбирает, какие папки из **опубликованного снимка** читать. Сайт на телефоне не получает доступ к диску компьютера. Чтобы добавить новую локальную папку, выберите её на компьютере и запустите обновление.

По умолчанию импортируются готовые ответы двух глав из `questions/`. Пустые файлы, `qst.md`, `catalog.md`, `AGENTS.md`, `README.md`, `*-draft.md` и скрытые папки исключаются. Другие имена можно исключить через `exclude` в конфиге. Исходные заметки не редактируются.

## Локальная проверка

```powershell
python -X utf8 publish.py --local
python -m http.server 8000 --directory dist
```

Откройте http://localhost:8000. Стрелки клавиатуры переключают карточки. На телефоне таблицы прокручиваются горизонтально внутри карточки.

## Устройство

- `web/` — простой интерфейс без сборщика; Markdown рендерится локальными копиями Marked и DOMPurify.
- `build.py` — собирает `dist/`, копирует локальные изображения и связывает импортированные Markdown-файлы.
- `publish.py` — отправляет только `dist/` в ветку `gh-pages` существующего репозитория. Рабочая ветка и её незакоммиченные изменения не затрагиваются. Служебный Git-индекс находится в `.publish/`.
- `sources.json` — папки и исключения. `dist/` и `.publish/` создаются автоматически.

Обычные Markdown-заголовки, списки, таблицы, цитаты, код, ссылки и изображения поддерживаются. Mermaid и LaTeX не исполняются; показываются как текст/код. Локальные изображения поддерживаются в обычной записи `![описание](image.png)`; пути с пробелами нужно URL-кодировать. Вложения вне папки-источника (либо родительской папки главы для `questions/`) не копируются. Ссылки на неимпортированные `.md` и другие локальные вложения не публикуются.

Сайт публичный. Токен GitHub берётся из Credential Manager только на время выполнения; в проект и на сайт он не записывается. Ветка `gh-pages` предназначена только для сгенерированного сайта. Первое включение Pages скрипт выполняет через [официальный API GitHub](https://docs.github.com/en/rest/pages/pages#create-a-github-pages-site).
