# Markdown-карточки

- Простой статический сайт: HTML, CSS, JavaScript; без сервера, аккаунтов и сборщика интерфейса.
- `web/` — исходники интерфейса; `build.py` собирает `dist/` из папок в `sources.json`.
- Один непустой Markdown-файл — одна карточка, без обрезки и фиксированной высоты. Сохранять Context, U:, A:, таблицы и код.
- Выбор директорий на сайте фильтрует опубликованную коллекцию. Локальные папки выбираются через `update.cmd --choose`; телефон не читает диск компьютера.
- Не менять исходные заметки. По умолчанию исключать очереди, каталоги, AGENTS и черновики.
- `update.cmd` вручную собирает сайт и публикует только `dist/` в ветку `gh-pages`. Не коммитить и не отправлять посторонние изменения основного репозитория.
- Сайт открытый. Не записывать токены в файлы, логи, URL или аргументы команд.
- Проверять импорт, относительные ссылки, навигацию, пустой выбор, запоминание позиции и мобильную ширину после изменений поведения.
- Обновлять README при изменении запуска или публикации. Сгенерированные `dist/`, `.publish/`, кэши не хранить в исходниках.
